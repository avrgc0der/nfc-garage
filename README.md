# NFC Garage

Interactive Mazda RX-7 and Shelby GT500 studio.

- [RX-7](https://avrgc0der.github.io/nfc-garage/rx7/)
- [GT500](https://avrgc0der.github.io/nfc-garage/gt500/)

This branch contains the ready-to-host production build. GitHub Pages publishes from `main` → `/ (root)`.

The complete source, dependencies lockfile, optimized models, and build instructions are included in [nfc-garage-source.zip](nfc-garage-source.zip).

Model and brand attribution: [attribution.txt](attribution.txt). Engine sounds are original procedural synthesis, not vehicle recordings.
